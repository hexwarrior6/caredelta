External models and hosted services

- DeepSeek API, model configured as deepseek-v4-flash — proprietary hosted model;
  use is governed by DeepSeek's current terms of use. CareDelta sends only
  locally redacted text and falls back to deterministic extraction on failure.
- Volcengine BigModel Speech Recognition flash API — proprietary hosted service;
  use is governed by Volcengine's current service terms. Audio is sent
  server-side for transcription and the transcript is editable before ingest.
- MongoDB Atlas — hosted database service; MongoDB server licensing and Atlas
  service terms apply.
- Railway — backend hosting platform; Railway service terms apply.
- Vercel — frontend hosting platform; Vercel service terms apply.

Project code and synthetic data

- CareDelta source code is released under the repository MIT License.
- All demonstration patients, identities, notes, transcripts, and clinical
  events are synthetic. No third-party clinical dataset is bundled.

Transitive dependencies are recorded in frontend/package-lock.json and the
installed Python dependency graph. No external source code, image, audio, or
clinical dataset is copied into this repository beyond ordinary dependencies.
